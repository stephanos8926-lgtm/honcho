## 2. Issues Found and Fixed

### 2.1 Critical Bug: `find_path()` Only Searched Outgoing Edges
**File:** `src/kg/graph.py:find_path()`
**Issue:** The BFS pathfinding only queried `KGRelationship.source_entity_id == current_id`, meaning paths through incoming relationships were invisible.
**Fix:**
- Changed query to check BOTH `source_entity_id` and `target_entity_id` using `or_()`
- Added `is_outgoing` flag to parent tracking (changed from 2-tuple to 3-tuple)
- Path reconstruction now correctly handles both directions for display
- Added `or_` import to file

### 2.2 Edge Case: `subgraph()` Edges Unbounded
**File:** `src/kg/graph.py:subgraph()`
**Issue:** The `limit` parameter capped entities but not edges. A densely connected entity could return thousands of edges.
**Fix:** Added `if len(edges) >= limit: break` inside the relationship loop, matching the behavior of entity capping.
